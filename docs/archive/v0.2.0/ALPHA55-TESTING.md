Open F9 and check the Quest; revisit the checkpoint and confirm it is not repeatedly announced. The removed custom sprite must not reappear after Menu/Resume or save/load.
4. Visit Hero Showcase and optional racial XP displays. Listen for unwanted upkeep transitions while large groups are transferred/spawned. Test one summon, then Back/Topics/exit and check cleanup. Normal hero stats, ownership and colors should still work.
5. Retest the previous [alpha54 checklist](ALPHA54-TESTING.md) where not already accepted: Mining mode tooltips, Build Order worker production and rallies, dummy mode/armor icons/tooltips and automatic Neutral transition after the Archmage attack-speed narration.

No new Hotkey audit is needed. Shift-queued worker jobs remain a known Build Order limitation. This build does not publish 0.2.0 or change public release links.
