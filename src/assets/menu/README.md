# Generated menu textures

These DDS files are generated by `tools/prepare-menu-art.py` from editable sources under `design/menu-art/`.

- The named activity textures are readable 1024×512 crops for illustrated cards.
- Prototype `*Hover.dds` and `ButtonHover.dds` files may be generated for visual experiments, but stable packaged builds do not import or use them.
- `TooltipGrey.dds` is a low-opacity neutral tooltip field.
- The nine `Tooltip*` edge, corner, and center textures form the current rounded tooltip without stretching its corners.
- Menu panels use Warcraft III's native racial `EscMenuBackdrop`; no full-menu texture is packaged.

The infrastructure builder imports these textures under `JTGMenu\` in packaged candidates.
