# Reference maps

This directory preserves historical maps and accepted playable baselines used to verify migrated behavior. Reference files should not be edited in place.

- `twisted-meadows/` contains the untouched terrain source used by the reproducible foundation build.
- `legacy/` contains interface and loading-screen assets extracted from Jamie's inherited map.
- `foundation/` contains the accepted `v0.0.1-alpha.5` playable baseline and its validation report.

The accepted foundation map has SHA-256 `a1ea7789e60b30e77d64f14337759842dff309d129929ef24defb1276cf1ba64`.
