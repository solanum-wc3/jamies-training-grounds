# Design material

This directory holds maintained editable design sources: menu-card compositions, obstruction-square artwork, Economy and Heroes narration/layout inputs, exercise briefings and Dodging catalogue/measurement data. See [project files](../docs/PROJECT-FILES.md) for source and generated boundaries.

Economy/Heroes JSON and the Hotkey/Reflex editable briefing text are authoritative inputs to their generators. Other tutorial Markdown and exercise text work files are authoring snapshots requiring manual import; preserve user edits when refreshing them. The original Heroes attachment remains outside the repository; the corrected work file and structured implementation are retained here.

A tutorial specification should describe:

- the scene and required map objects;
- the instruction shown to the player;
- the action the player is invited to try;
- Continue, Back, and checkpoint behavior;
- reset and cleanup expectations;
- any information worth preserving between sessions.
